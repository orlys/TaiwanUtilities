## 資料授權 (OGDL-Taiwan-1.0)

### 適用範圍

政府資料開放授權條款第 1 版適用於：

#### 郵遞區號資料
- 編譯進函式庫的郵遞區號資料（`PostalData.g.cs`）
- 從中華郵政取得的原始郵遞區號資料
- 由該資料衍生的索引和查詢結果

**提供者：** 中華郵政股份有限公司
**資料集：** 3+3 郵遞區號資料
**資料網址：** https://data.gov.tw/dataset/25489

#### 辦公日曆表資料
- 嵌入的假日 CSV 資料 (`data/holidays/*.csv`)
- 從行政院人事行政總處取得的辦公日曆表

**提供者：** 行政院人事行政總處
**資料集：** 辦公日曆表
**資料網址：** https://data.gov.tw/dataset/14718

### 使用條件

**允許的使用：**
- 商業用途
- 修改和衍生
- 重製和散布
- 公開傳輸
- 再轉授權

**必須遵守（署名要求）：**

使用本專案的政府資料時，您必須：

1. **保留資料來源標示**
   ```
   資料來源：中華郵政股份有限公司、行政院人事行政總處
   授權：政府資料開放授權條款第 1 版 (OGDL-Taiwan-1.0)
   ```

2. **若修改資料，需聲明變更**
   - 說明修改了哪些內容
   - 註明修改日期

3. **不得以政府機關或資料提供者名義發布**

### 範例標示

#### 最簡標示（最低要求）
```
郵遞資料來源：中華郵政
假日資料來源：行政院人事行政總處
```

#### 完整標示（建議）
```
本產品使用中華郵政股份有限公司提供的郵遞區號資料
及行政院人事行政總處提供的辦公日曆表資料
授權條款：政府資料開放授權條款第 1 版 (OGDL-Taiwan-1.0)
```

## 常見問題

### Q: 可以在商業專案中使用嗎？
**A:** 可以。程式碼（MIT）和資料（OGDL-Taiwan-1.0）都明確允許商業使用。

### Q: 修改代碼需要開源嗎？
**A:** 不需要。MIT License 允許您保持修改為閉源。

### Q: 如何正確標示資料來源？
**A:** 最簡單的方式是在您的應用程式說明、關於頁面或文件中加入：
```
資料來源：中華郵政、行政院人事行政總處
```

### Q: NuGet 套件的授權是什麼？
**A:** NuGet 套件包含程式碼（MIT）和內嵌的政府開放資料（OGDL-Taiwan-1.0），使用時需遵守兩者的授權條款。套件中已包含完整的 LICENSE 和 NOTICE.md 文件。

### Q: 如何查看完整授權條款？
**A:**
- MIT License：查看專案根目錄的 [LICENSE](../LICENSE) 檔案
- OGDL-Taiwan-1.0：查看官方網站 https://data.gov.tw/license
